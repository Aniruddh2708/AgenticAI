## Brand & Style

This design system establishes a cybernetic, mission-critical operational deck engineered for high-concurrency multi-agent AI systems, deep financial telemetry, and auditable algorithmic reasoning. The aesthetic fuses high-tech utilitarianism with precision cybernetics, moving far beyond generic corporate dashboards into an immersive, focused command console.

### Brand Personality & Core Principles
- **Algorithmic Rigor & Explainability:** Visual hierarchy prioritizes clarity over ornamentation. Agent concurrency, consensus stages, latency logs, and citation links are rendered with immediate factual legibility.
- **Calm, High-End Utility:** A rich, bio-computational abyssal spruce base eliminates screen glare during sustained deep analytical work while establishing endless depth.
- **Phosphorescent Direction:** Neon electric lime illuminates actionable directives, confidence scores, and synthesis conclusions, while telemetry cyan indicates active agent stream threads.
- **Auditable Integrity:** Critical signals, document citation marks, and risk thresholds avoid ambiguous states through high-contrast badges and clear status geometry.

### Style Archetype
- **Neo-Terminal Cybernetics:** Dark frosted glass surfaces, hairline verdigris structural framing, geometric typography paired with dense tabular monospacing, and zero reliance on heavy drop shadows. Depth is achieved purely through stacked luminescence tiers, crisp 1px borders, and focused ambient glows.

## Colors

The color system operates on an active multi-tiered dark foundation, categorizing visual real estate into deep analytical context, actionable nodes, and high-visibility evidence markers.

### Palette Architecture
- **Primary (`#c4f270` - Electric Lime):** The apex directive accent. Used exclusively for primary action triggers, confirmed multi-agent synthesis conclusions, active confidence progress tracks, and primary status flags. Paired with `on-primary-dark` (`#0d2100`) for high text legibility.
- **Secondary (`#b2c9be` - Sage Slate):** Subdued functional balance. Serves as secondary button boundaries, secondary active tabs, metadata headings, and non-critical metrics.
- **Tertiary (`#4ee2d4` - Telemetry Cyan):** Used for parallel live stream channels, concurrent agent node data flow connectors, and dynamic query vectors.
- **Neutral (`#071b1b` - Abyssal Spruce):** The foundational infinite-depth dark canvas. Its deep teal-tinted undertone grounds components without the stark optical fatigue of pure `#000000`.

### Functional Status & Signal Colors
- **Bullish / Concurrence (`#81c784` edge, `#c8e6c9` fill):** Affirms positive market signal, verified agent consensus, and validated claim anchors. Internal text switches to `ink-contrast` (`#151515`) when placed inside filled badge pills.
- **Bearish / Anomaly (`#ff8a80` edge, `#ffcdd2` fill):** Denotes downward metric shifts, agent timeout bypasses, or safety guardrail violations.
- **Neutral / Warning (`#ffd89c` edge, `#fff3cd` fill):** Topaz warning for inconclusive signals, degraded agent execution fallback, or document excerpt highlights.

## Typography

The typographic hierarchy creates a deliberate dual-system harmony between analytical display headings, comfortable long-form explanatory narratives, and ultra-precise algorithmic telemetry.

### Typographic Roles
- **Headlines (`Space Grotesk`):** Delivers a technical, cutting-edge geometric rhythm. Large display sizes feature tight negative tracking (`-0.035em` to `-0.04em`) to forge a dense, authoritative presence for primary synthesis declarations.
- **Narratives & Synthesis Body (`Inter`):** Neutral, utilitarian, and exceptionally legible in low-light environments. Used for synthesized multi-agent rationales, regulatory summaries, and financial reports.
- **Telemetry, Metrics & Citations (`JetBrains Mono`):** Dedicated to numeric speedups, execution latencies (e.g. `14.2 ms`), SHA256 citation hashes, and tabular financial tickers. Numeric elements always enforce `tabular-nums` for seamless vertical alignment across dynamic data tables.
- **Eyebrows & Category Caps:** Styled using `label-caps` in uppercase with wide tracking (`0.18em`) and `#c4f270` coloration to structure distinct intelligence domains.

## Layout & Spacing

The layout system is founded on a 12-column responsive grid anchored around a strict 4px / 8px baseline rhythm. It organizes parallel telemetry modules and deep drill-down inspections into balanced, scannable hierarchies.

### Grid & Breakpoint Architecture
- **Desktop (1024px+):** 12-column fluid grid bounded by a max canvas width of `1440px`, flanked by `margin` (`2.5rem` / `40px`) and `gutter` (`1.125rem` / `18px`). Accommodates multi-agent matrix feeds: 3-column orchestrator decks, collapsible side-by-side agent logs, and comparative what-if portfolios.
- **Tablet (768px - 1023px):** 8-column layout with `1.5rem` margins. Parallel agent cards collapse into a 2-column alternating grid, with slide-over drawers for source verification and claim citations.
- **Mobile (<768px):** 4-column single stream layout with `margin-mobile` (`1rem` / `16px`) and `gutter-mobile` (`0.75rem` / `12px`). Real-time telemetry indicators and multi-agent health status pills become horizontally swipeable carousels.

### Spacing Philosophy
- **Component Padding (`space-lg` / `24px` on desktop, `space-md` / `16px` on mobile):** Provides breathing room inside dense frosted cards without spreading related evidence nodes too far apart.
- **Micro-Gaps (`space-xs` to `space-sm`):** Reserved strictly for badge items, agent pulse dots, latency metrics, and inline ticker pairs.
- **Section Separation (`space-xl` to `space-2xl`):** Major functional tiers (Input Parameter Bar, Agent Concurrency Matrix, Synthesis Outcome Banner, Evidence Claims Inspector) maintain distinct vertical separation to prevent cognitive overload.

## Elevation & Depth

Visual depth is communicated without muddy shadow layers. In place of heavy skeuomorphic drop shadows, the system deploys **Tonal Luminescence, Translucent Glass Layers, and Hairline Verdigris Framing**.

### Surface Hierarchy
1. **Bedrock Canvas (`#071b1b`):** The non-interactive ground tier of the command center.
2. **Standard Surface Container (`#102a29` with 90% opacity & `backdrop-filter: blur(12px)`):** Applied to agent node cards, tabular telemetry panels, and persistent navigation bars.
3. **Elevated Surface (`#183c3a`):** Active card hovers, modal overlays, active drawer panels, and high-priority recommendation modules.
4. **Interactive Focus Layer (`#214c49`):** Popovers, dropdown menus, and nested claim inspection chips.

### Border & Luminescent Halos
- **Hairline Framing:** Every container, input field, and divider is circumscribed by a crisp `1px solid #35514c` verdigris stroke.
- **Interactive Phosphor Glow:** Interactive buttons, active slider thumbs, and focused agent nodes project an ambient lime halo:
  - *Primary Button Hover:* `box-shadow: 0 0 16px rgba(196, 242, 112, 0.35)`
  - *Active Telemetry Node:* `box-shadow: 0 0 20px rgba(78, 226, 212, 0.18)`
  - *Focus Halo:* `0 0 0 2px rgba(196, 242, 112, 0.45)`

## Shapes

The interface balances cybernetic discipline with comfortable modern usability via structured corner rounding:
- **Base Rounding (`roundedness: 2` / `0.5rem` / `8px`):** Standard interactive elements such as code badges, tabular chips, and input textboxes.
- **Control & Button Geometry (`10px`):** Sits between standard base and large cards to ensure primary buttons feel tactile and distinct.
- **Card & Node Frames (`rounded-lg` / `1rem` to `18px`):** Softens dense multi-agent cards and recommendation banners, maintaining structural clarity against adjacent panels.
- **Status Pills & Toggles (`rounded-full` / `9999px`):** Agent telemetry status pills, categorical indicators, and pill-shaped tab selectors.

## Components

### 1. Buttons & Triggers
- **Primary Execution Button:** Solid `#c4f270` fill, `#0d2100` bold typography, `10px` border-radius. On hover: shifts background to brighter neon `#d9f99d` and emits an outer luminescent halo (`box-shadow: 0 0 16px rgba(196, 242, 112, 0.35)`). Active click scales slightly to `0.98`.
- **Secondary / Ghost Button:** Background `#102a29`, border `1px solid #35514c`, text `#eef7ec`. On hover: border transforms to `#c4f270` and text glows `#c4f270`.
- **Icon / Telemetry Trigger:** Square `36px × 36px` container with subtle `#183c3a` background and verdigris border, displaying monospaced icons or status glyphs.

### 2. Multi-Agent Concurrency Cards
- Modular grid cards representing parallel agents (Filings, Momentum, Risk, Sentiment, Volume).
- **Structure:** `18px` rounded corners, `#102a29` frosted surface, `1px solid #35514c` perimeter.
- **Header:** Left-aligned agent identifier with uppercase eyebrow styling; right-aligned wall-clock latency tag rendered in `code-inline` (e.g. `14.2ms`).
- **Health Pulse Indicator:** An 8px status orb:
  - *Healthy:* Pulsing `#81c784` with solid `#35514c` ring.
  - *Degraded:* Warning `#ffd89c` dot with a secondary warning tooltip.
  - *Failed / Bypassed:* `#ff8a80` alert dot with bypass trace identifier.
- **Agent Signal Pill:** High-contrast badge displaying outcome direction (`BULLISH`, `BEARISH`, `NEUTRAL`) using dedicated signal fills and `#151515` text.

### 3. Synthesis Decision Banner
- High-impact outcome card summarizing orchestrator consensus.
- **Visual Stance:** Features a heavy left border accent (4px solid `#c4f270`) on `#102a29` background.
- **Core Directive:** Massive `display-lg` headline rendering actionable directive (`BUY`, `HOLD`, `REDUCE`, `SELL`).
- **Confidence Gauge:** Dual-track meter with `#183c3a` track and `#c4f270` glow bar, accompanied by a numeric score in `stat-lg` (`88/100`).
- **Safeguard Attribution Chip:** Clear visual badge indicating whether the synthesis represents raw market consensus or has been filtered by hard risk guardrails (e.g., concentration ceilings, volatility rules).

### 4. Evidence Claim & Citation Inspector
- **Accordion Wrapper:** Multi-tiered filing disclosure drawer with `1px solid #35514c` boundary.
- **Passage Highlight Container:** Dark terminal frame (`#051414`) containing monospaced disclosures. Citations are highlighted using `<mark>` spans styled with `#ffd89c` amber background and `#151515` text for instant scanning.
- **Hash Badge:** Monospaced pill displaying filing chunk hash (e.g. `SHA-256: 7d4a...`) and retrieval cosine similarity score.

### 5. Input Fields & Selectors
- **Query & Ticker Inputs:** Background `#0a2120`, border `1px solid #35514c`, text `#eef7ec`, radius `10px`. Placeholder styled in muted `#b2c9be`. Focus state transitions border to `#c4f270` with a 2px diffuse verdigris glow.
- **Dual-Thumb Risk Sliders:** Track styled in `#183c3a` with `#c4f270` active fill. Draggable thumb is a crisp 16px circle with `#c4f270` core and subtle glow.

### 6. Workflow Pipeline Nodes & Connectors
- **Connectors:** 1.5px verdigris `#35514c` stroke with animated telemetry flow pulses in `#4ee2d4`.
- **Node Geometry:** Pill-shaped connectors highlighting orchestration flow (`Raw Feed -> Agent Chamber -> Synthesis -> Safety -> Final Telemetry`).
