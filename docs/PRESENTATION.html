Evidence, not performance claims

Measure the demo.
Do not sell it as market edge.

Latency

Use the real sequential-versus-parallel benchmark on equal inputs. Thread overhead can exceed gains for tiny deterministic workloads.

Direction evaluation

Read the generated sample size, intervals, baselines and forward returns. Synthetic results do not demonstrate future investment returns.

Confidence

Signal strength, an up-direction probability and confidence in an action are different quantities. Calibration requires a defined outcome.

Open the running Metrics tab or generated evaluation report for current values. This deck intentionally contains no frozen accuracy number that could become stale after a code change.

Source identity and passage matching provide provenance. Deterministic claim checks cover the supported extraction rules; they are not a general proof of factual truth.
